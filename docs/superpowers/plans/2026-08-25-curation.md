### Task 1: `ManualEvent` model + id line in descriptions
- Modify `sports_calendar/models.py`: add `ManualEvent(uid, title, start: date|datetime, end: date|datetime, description="", matched_rules=[])`.
- Modify `sports_calendar/ics.py`: `description_for` and all-day descriptions end with `id: {uid}`; `_simple_event(e)` renders `AllDayEvent` and `ManualEvent`; `build_calendar(games, alldays, display_names)` accepts `ManualEvent`s in `alldays`.
- Tests (`tests/test_ics.py`): description ends with `id: espn-1`; a timed `ManualEvent` renders DTSTART/DTEND datetimes.
- Commit: `feat: ManualEvent and id line in event notes`

### Task 2: `curation.py`
- Create `sports_calendar/curation.py`:
  - `local_day(item, tz) -> date` — Game with valid start → `start.astimezone(tz).date()`, else `item.day`; events → `item.start` (date or local date of datetime).
  - `matches(entry, item, title, tz) -> bool` — fields `id`, `title`, `between`, `sports`, `rules`; validates keys (`ValueError` on unknown/empty).
  - `apply_excludes(games, events, excludes, display_names, tz) -> (games, events)`.
  - `build_extras(entries, tz) -> list[ManualEvent]` — dates → all-day (`end` inclusive → exclusive), datetimes → timed (`hours` default 2, naive → `tz`); strings accepted via `fromisoformat`.
- Tests (`tests/test_curation.py`): exclude by title+between where a 01:30Z game lands on the previous Denver day; by sports+between (leaves soccer); by id; by rules; empty/unknown entry raises; extras single-day, multi-day, timed with hours, naive datetime localized, stable uid.
- Commit: `feat: exclude and extra config sections`

### Task 3: wire into `main.run` + config + README

- `config.yaml`: add `timezone`, and empty `exclude: []` / `extra: []` with commented examples.
- `tests/test_main.py`: temp config = config.yaml + exclude of `Pirates Mets` on 2026-03-26 + extra all-day event; assert Opening Day absent and extra present.
